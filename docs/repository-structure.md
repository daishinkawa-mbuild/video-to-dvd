# リポジトリの構成計画

## 目的

このモノレポは、DVD作成処理とmacOSアプリを同じリポジトリで管理します。
一般の利用者は、動画選択、変換結果の確認、DVDへの書き込みを画面から操作します。
開発者は、アプリを起動せずにDVD処理だけを実行・検証できます。

## ディレクトリと責務

| 配置先 | 責務 | 今回の対象 |
| --- | --- | --- |
| `apps/macos/` | SwiftUIアプリの画面、操作状態、ファイル選択、DVD処理の呼び出し | 将来作成 |
| `packages/dvd-engine/` | 入力検査、変換、DVDオーサリング、ISO作成、検証、書き込み | 既存スクリプトを配置 |
| `scripts/` | リポジトリ全体のビルド、依存ツールの梱包、署名、公証、DMG作成 | 将来作成 |
| `docs/` | リポジトリの構成と、実装に伴って必要になる設計・配布手順 | 本計画を配置 |
| `.github/workflows/` | 各パッケージの検証と、将来のリリース自動化 | シェルの構文・起動確認を追加 |

将来作成するディレクトリは、実装する段階で追加します。
空のディレクトリや、まだ使わないパッケージ管理設定は追加しません。

```text
video-to-dvd/
├── apps/
│   └── macos/                   # 将来追加するSwiftUIアプリ
│       ├── Sources/
│       ├── Resources/            # 同梱するDVD処理と依存ツール

│       ├── dvd-pipeline.sh       # 変換、ISO作成、書き込み、一時領域の解放
```

## 依存関係

`apps/macos` は `packages/dvd-engine` を呼び出します。
DVD処理はアプリの画面や状態管理に依存しません。
アプリのビルド時に、DVD処理をアプリのリソースへコピーします。
開発者は `packages/dvd-engine/dvd-create.sh` を直接実行することもできます。

現時点のエンジンは、`ffmpeg`、`ffprobe`、`dvdauthor`、`dvdunauthor`、
`mkisofs` と、macOS標準の `hdiutil`、`xmllint` を使用します。
今回の取り込みでは、依存ツールのバイナリをリポジトリへ追加しません。

アプリ化する段階で、呼び出し側は同梱ツールのパスを指定し、
エンジンは進捗、終了状態、キャンセルを画面から扱えるようにします。
アプリは引数配列でプロセスを起動し、利用者が指定したパスをシェル文字列に埋め込みません。
ツールの梱包処理は `scripts/` が担当し、DVDの変換処理と分離します。

## 配布方針

一般向けのアプリは、必要な依存ツールを同梱し、Homebrewの導入を不要にします。
配布処理は、アプリと同梱実行ファイルへのDeveloper ID署名、Appleの公証、
公証チケットの添付を行い、DMGとして公開します。
署名用の秘密鍵や公証用の認証情報は、リポジトリへ保存しません。

自作コードにはMITライセンスを適用します。
外部ツールを同梱する前に、各ツールとその依存ライブラリの再配布条件を確認し、
必要なライセンス文書とソースコードの提供方法を配布物に含めます。

## 実装の順序

1. 今回のスクリプトを取り込み、公開用の実行例とCIを整備します。
2. macOSアプリから呼び出すための進捗・キャンセル・実行結果の扱いを整えます。
3. 動画選択、変換結果の確認、書き込み、追加コピー作成の画面を実装します。
4. 依存ツールの梱包と、署名・公証済みDMGの作成を自動化します。
5. 開発ツールが入っていないMacで、導入からDVD作成まで確認します。

今回のCIはシェルの構文とヘルプ起動を確認します。
ISO作成、ソフトウェア再生、光学ドライブへの書き込みは、別途macOS上で検証します。
