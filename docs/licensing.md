# 公開・同梱時のライセンス方針

## 自作コードのライセンス

このプロジェクトが独自に作成したコードと文書には、[MITライセンス](../LICENSE)を適用します。
第三者のライセンス原文と著作権表示には、各文書の条件が適用されます。
再配布する人は、MITの著作権表示と許諾文を保持してください。
第三者からコードを取り込む場合は、取り込む前に適用条件とMITとの互換性を確認します。

外部ツールのコード、実行ファイル、ライブラリには、それぞれのライセンスが適用されます。
自作コードのMITライセンスは、外部ソフトウェアのライセンスを置き換えません。
各ツールの用途と確認状況は、[外部ソフトウェアの一覧](../THIRD_PARTY_NOTICES.md)に記載します。

## ソースコードを公開する場合

現在の配布対象は、自作コードと文書です。
利用者は外部ツールを別途導入し、DVD処理エンジンはそれらをコマンドとして実行します。
この配布形態では、外部ツールのバイナリやソースコードを再配布しません。

公開する人は、入力動画、写真、市販音源、DVDイメージ、個人文書を公開対象に含めません。
サンプルには、公開と再配布が許諾された素材を使い、必要な出典とライセンスを添えます。
署名用の秘密鍵、公証用の認証情報、個人情報が残ったログも公開対象から除外します。

## macOSアプリに外部ツールを同梱する場合

アプリは、外部ツールを独立した実行ファイルとして別プロセスで呼び出す構成を基本にします。
この構成でも、配布者は各実行ファイルと依存ライブラリの再配布条件を満たす必要があります。
別プロセスであることだけで、作品の独立性やライセンスの互換性を断定しません。
FFmpegなどのライブラリを直接リンクする構成へ変更するときは、適用条件を改めて確認します。

配布者は、開発用のHomebrewバイナリをそのまま配布物へコピーしません。
同梱候補の版、ビルド設定、パッチ、ライブラリを固定してから、以下を確認します。

| 対象 | 同梱前に行うこと |
| --- | --- |
| FFmpeg / ffprobe | 実際のビルドに適用されるLGPL/GPLの版を確認し、再配布できる構成を選びます。 |
| dvdauthor / dvdunauthor | GPLの原文・著作権表示を保持し、対応するソースを提供します。 |
| mkisofs / cdrtools | コンポーネント別のライセンスと、組み合わせの互換性を確認します。 |
| 依存ライブラリ | 動的・静的リンクの両方を調べ、各ライブラリの条件を確認します。 |
| macOS付属コマンド | OSが提供するものを実行し、このプロジェクトの配布物にはコピーしません。 |

### FFmpegの構成

FFmpegの上流ライセンスは通常LGPLですが、GPL部品や外部ライブラリを有効にすると変わります。
確認した開発環境のFFmpegはGPL-3.0-or-laterであり、LGPL版として扱えません。
GPL版を配布する場合も、必要な表示と対応ソースの提供を行います。
FFmpegの `--enable-nonfree` を有効にした再配布不可のビルドは、同梱候補から外します。

初回の同梱候補では、必要な入力形式とDVD用MPEG-2・AC-3出力に機能を絞り、
GPL部品や不要な外部ライブラリを有効にしない構成を検討します。
LGPL構成であっても、ライセンス表示や対応ソースの提供などの条件は残ります。
静的リンクを採用する場合は、該当するLGPLの再リンク条件なども確認します。
これはビルド方針であり、このリポジトリには配布用FFmpegをまだ用意していません。

### 対応するソースコードの提供

ダウンロード配布では、同梱バイナリと対応ソースのアーカイブを同じリリースで提供する方針です。
配布者は、上流のトップページや最新版へのリンクだけで対応を済ませません。
ソースの提供範囲と方法は、実際に採用した各ライセンスの条件に従って確定します。

対応ソースには、採用した版のソース、適用パッチ、必要なビルドスクリプトと設定を含めます。
必要な依存ライブラリについても、対応ソースと原文ライセンス・著作権表示を用意します。
バイナリの版、アーキテクチャ、ハッシュ値と、対応するソースの取得先を記録します。
ビルド時の出力やハッシュ値だけでは、対応ソースの提供の代わりにはなりません。

GPLv2とGPLv3では提供方法の条項が異なるため、利用する版に沿って確認します。
ネット配布で使うソース提供方法を、DVDなどの物理媒体による配布にそのまま適用しません。
将来物理媒体で配布するときは、ソースの同梱や書面による申出などの条件を再確認します。

## バイナリを公開する前の確認

以下は、依存ツールを同梱するリリースで実施します。
現在は配布用バイナリが未確定のため、以下の項目は完了していません。

- [ ] 配布物から、実行ファイルと動的・静的に取り込んだ依存物をすべて列挙する。
- [ ] 各依存物の版、入手元、ハッシュ値、ライセンス、著作権表示を確定する。
- [ ] FFmpegのビルド設定と外部ライブラリを確認し、再配布不可の組み合わせを除外する。
- [ ] mkisofsと関連するGPL/CDDL構成の扱いを確認する。
- [ ] 同梱物ごとの原文ライセンスと必要な通知文を、アプリから参照できる形で含める。
- [ ] 対応ソースとビルドに必要な情報を公開し、リリースから取得できることを確認する。
- [ ] 第三者が、配布したソースと説明から依存ツールをビルドできることを確認する。
- [ ] 利用規約が、GPL/LGPLなどで認められた再配布・改変の権利を制限していないか確認する。
- [ ] 署名・公証後の配布物にも、通知文とソース取得先が含まれていることを確認する。

Mac App Storeで配布する場合は、ストアの配布条件と各依存物のライセンスの両立を別途確認します。
Developer ID署名やAppleの公証は、OSSライセンスへの適合性を保証するものではありません。
